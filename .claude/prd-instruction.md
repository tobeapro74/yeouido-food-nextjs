# 여의도 한끼 - 프로젝트 요구사항 정의 (PRD)

## 프로젝트 개요

**프로젝트명**: 여의도 한끼
**목적**: 여의도 직장인을 위한 맛집 추천 웹 애플리케이션
**타겟 사용자**: 여의도 근무 직장인 (점심/저녁 식사 결정이 어려운 분들)

## 핵심 가치

1. **빠른 의사결정**: "오늘 뭐 먹지?" 고민 해결
2. **지역 특화**: 여의도 맛집만 엄선
3. **신뢰성**: 실제 운영 중인 식당만 표시 (폐업 자동 필터링)

1. **사용성**: 3번의 탭 이내 식당 결정
